## 当前外部资源与范围边界

1. 旧 Card-only P4 继续或停止条件 仍是该历史矩阵的 停止，不限制按 第四阶段的记录整理办法 新实验开始前定下的规则运行 τ³ development 实验；也不得被 第四阶段的记录整理办法 工程完成追溯改成 Go。
2. 第四阶段的记录整理办法 外部运行只允许实验开始前定下的规则的免费 `zai/glm-4.7-flash`，无付费/模型 fallback；价格、额度和零成本估算必须在启动时重新核验。
3. 当前 60-session 修复后复合数据集可用于负结果和 measurement 分析，但不得写成一次连续运行或正式 human-validated P3 成功。
4. 两位独立人工 事先规定的标准答案 与第二 benchmark 未包含在本轮 τ³-only development 范围；没有它们不得声称最终 construct validity 或 AAAI 双 benchmark evidence。
5. E0、R2、R3 任一继续或停止条件失败都要求停止；不得挑任务、降低阈值、增加样本或自动补跑以追求正向结论。
