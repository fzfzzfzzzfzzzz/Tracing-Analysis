 3. 存储规范 (重要)
 为了保证系统盘空间充足，请务必遵守以下存储原则：
 • /home/fangc: 仅存放代码、配置文件；建议占用避免超过150GB。
 • /data/fangc (或 /date/): 存放所有数据集、模型权重、实验输出日志、Conda 环境；建议避免占用超过1TB。
 • 清理: 实验结束后请及时清理不再需要的中间 checkpoint。

 4. 网络环境说明
 四台 3090 均需在校园网环境下访问； A100 机器需要挂载VPN访问，详情参见：A100连接指南
 3090 服务器由于中过病毒，nvidia-smi 命令并不总是可信，建议使用 gpustat 命令稳定代替。

 5. 进阶：跳板机配置
 针对需要跳转访问的 .158 机器，建议在你的本地电脑 ~/.ssh/config 中添加如下配置，之后直接 ssh lab158 即可：
   Host lab-jump
       HostName 10.103.10.157
       User fangc

   Host lab158
       HostName 10.103.10.158
       User fangc
       ProxyJump lab-jump

 6. 实验室生存守则
 1. 先看后用: 跑程序前请先执行 gpustat 查看显存。严禁在显存已满的卡上强行拉起程序。
 2. 持久化: 训练任务请务必在 tmux 或 screen 会话中运行，防止网络波动导致训练中断。
